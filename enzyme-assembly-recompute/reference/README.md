# Source records

- [data_provenance.json](data_provenance.json): source identification, extraction method, and checksums.
- [paper_reported_results.json](paper_reported_results.json): source-manuscript values retained separately from computed outputs.

The source Word file is optional local material and is not required for the CSV-based analysis. Its default local path is excluded by `.gitignore`. See the [data card](../docs/data_sources.md) for verification and rights information.
